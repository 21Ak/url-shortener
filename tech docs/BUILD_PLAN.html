Entity

Helper: ShortCodeGenerator
Helper — Strategy pattern, SHA-256 → Base62
Helper
📦 What to build
  • Create ShortCodeGenerator.java — interface with String generate(String originalUrl)
  • Create HashBasedShortCodeGenerator.java (@Component): SHA-256 hash of (url + System.nanoTime()) → take first 8 bytes → convert to long → Base62 encode → 7 chars
  • Constants: BASE62 = "0-9A-Za-z", CODE_LENGTH = 7
🗂 Files created
ShortCodeGenerator.java HashBasedShortCodeGenerator.java HashBasedShortCodeGeneratorTest.java
🧪 Tests (4 tests)
  • Generated code is exactly 7 characters long
  • Generated code contains only Base62 characters [0-9A-Za-z]
  • Two consecutive calls produce different codes (nanoTime salt)
  • Generate 10,000 codes → uniqueness rate > 99.9%
mvn test -Dtest=HashBasedShortCodeGeneratorTest

Service Layer (Interface + Implementation)
Service — Business logic orchestration
Service
📦 What to build
  • Create UrlService.java interface — shortenUrl(ShortenUrlRequest) and getOriginalUrl(String)
  • Create UrlServiceImpl.java (@Service) — constructor-injects repository, shortCodeGenerator, transformer, urlValidator
  • shortenUrl(): validate → generate unique code (retry up to 3x) → transform to entity → save → transform to response
  • getOriginalUrl(): findByShortCode → map to originalUrl → orElseThrow UrlNotFoundException
  • Private generateUniqueShortCode() with collision retry loop
🗂 Files created
UrlService.java UrlServiceImpl.java UrlServiceImplTest.java
🧪 Tests (6 tests — Mockito)
  • shortenUrl happy path — mock all deps, verify response fields
  • shortenUrl with invalid URL — urlValidator throws → exception propagated
  • shortenUrl with 1 collision then success — existsByShortCode: true → false
  • shortenUrl with 3 collisions — throws ShortCodeCollisionException
  • getOriginalUrl happy path — returns original URL string
  • getOriginalUrl not found — throws UrlNotFoundException
mvn test -Dtest=UrlServiceImplTest
